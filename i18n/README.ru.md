NeoSwitch позволяет переключать отдельные сессии Claude Code на модель Google Gemini 4 Neon, сохраняя ваши настройки Claude Code, коннекторы, разрешения и остальные окна без изменений.

[![Настройка NeoSwitch в три шага](../docs/media/neoswitch-demo.gif)](../docs/media/neoswitch-demo.mp4)

Переключайте по одной сессии — остальные окна в том же проекте продолжают работать с Claude. Плагин работает в macOS и Linux; Windows пока не поддерживается.

## Ключевые возможности

- **По одной сессии и возврат на месте.** `/neoswitch:on` и `/neoswitch:off` действуют только на текущую сессию со следующего сообщения; остальные окна в том же проекте и новые сессии остаются на Claude, а при закрытии последней переключённой сессии записи NeoSwitch автоматически удаляются из проекта.
- **Claude Code остаётся самим собой.** `ANTHROPIC_AUTH_TOKEN` не записывается, поэтому коннекторы `claude.ai` продолжают работать; встроенный `WebSearch` ищет в Google через Antigravity; режим Auto работает из коробки с fail-closed классификатором безопасности (без перезапуска и расхода Claude); `/effort` и опциональные блоки размышлений (`NEOSWITCH_SHOW_THINKING`) аккуратно отображаются в Gemini.
- **Мгновенные нативные команды и живая квота.** В Claude Code 2.1.326 и новее `/neoswitch:login`, `/neoswitch:on`, `/neoswitch:off` и `/neoswitch:status` отвечают напрямую без хода модели, строка под приглашением показывает активную модель, а `/neoswitch:status` без расхода квоты выводит 5-часовые и недельные полосы лимита Antigravity и время сброса (`-v` добавляет все группы и кредиты).
- **Готов к длинным рабочим сессиям.** Переиспользование и разбиение ACP-сессий обходят ограничение `agy` в 192 КБ, облегчённый агент снижает накладные расходы `agy` с ~14k до менее 1k токенов, параллельные вызовы инструментов чинят JSON-экранирование, а подсказки и заголовки сессий идут в `gemini-3.8-flash` для экономии квоты Gemini 4 Neon.
- **Локально, изолированно, обратимо.** Трафик идёт только по локальному TLS с уничтожением приватного ключа CA сразу после подписи; NeoSwitch никогда не читает, не хранит и не переиспользует OAuth-токены Google; `agy` запускается в изолированной папке, где его файловые и shell-инструменты заблокированы и облегчённым агентом, и проверяемым хуком `PreToolUse`; ваши `NODE_EXTRA_CA_CERTS` и `ANTHROPIC_CUSTOM_HEADERS` сохраняются и восстанавливаются при выключении.
- **Удобен по SSH и обновляется без разрывов.** `/neoswitch:login` открывает браузер и выводит ссылку с кодом для удалённых/SSH-машин, обновления плагина автоматически передают порт новому демону без закрытия окон, а при сбое сборки или загрузки используется кэшированный релиз, чтобы `/neoswitch:off` всегда работал.
- **Несколько бэкендов.** Используйте аккаунт Google через официальный `agy`, либо `GEMINI_API_KEY`, Vertex AI или экспериментальный бэкенд OpenAI Responses.

## Быстрый старт

**1. Установите плагин.** В Claude Code выполните эти две строки по очереди. Копируйте каждую строку целиком: в первой написано `neo-switch`, во второй `neoswitch`.

```text
/plugin marketplace add yldm-ai/neo-switch
```

```text
/plugin install neoswitch@neoswitch
```

Включите автообновление, чтобы исправления приходили сами при изменениях в Google или Claude Code: выполните `/plugin`, откройте вкладку **Marketplaces**, выберите `neoswitch` и включите auto-update. Для сторонних маркетплейсов Claude Code держит его выключенным по умолчанию.

**2. Войдите через аккаунт Google.** Откройте Claude Code в проекте, который хотите переключить, и выполните:

```text
/neoswitch:login
```

Команда покажет предупреждение об условиях Google, при отсутствии установит официальный [Antigravity CLI (`agy`)](https://antigravity.google/download) в `~/.local/bin` (~230 МБ), откроет вход в Google в браузере и включит эту сессию. Также выводится ссылка для удалённых/SSH-машин: откройте её на любом устройстве, войдите и вставьте код в диалог Claude Code 2.1.326+ (или выполните `/neoswitch:login <code>` в более старых версиях, WSL или десктоп-приложении через SSH). Повторный `/neoswitch:login` переключает аккаунт Google, а `/neoswitch:login cancel` оставляет текущий. Нужен API-ключ или Vertex AI? См. [docs/cli.md](../docs/cli.md#gemini-api-key) (на английском).

> [!WARNING]
> [Условия использования Google Antigravity](https://antigravity.google/terms) (раздел 6) запрещают пользоваться Antigravity через другие инструменты, а NeoSwitch как раз такой инструмент. Google может заблокировать или закрыть аккаунты Antigravity тех, кто так делает. `/neoswitch:login` каждый раз повторяет это предупреждение. Не входите, если не готовы принять этот риск.

**3. Отправьте следующее сообщение.** Эта сессия отвечает с помощью Gemini 4 Neon со следующего сообщения, пока другие окна и новые сессии остаются на Claude. Если ответ просит перезапуститься из-за запуска Claude Code через шлюз, снова запустите `claude` без шлюза в том же проекте.

| Команда | Что делает |
|---|---|
| `/neoswitch:login [code \| cancel]` | Вход через официальный `agy`, смена аккаунта Google или завершение SSH-входа по коду с включением этой сессии |
| `/neoswitch:on` | Переключить эту сессию на Gemini 4 Neon со следующего сообщения |
| `/neoswitch:off` | Вернуть эту сессию на Claude со следующего сообщения |
| `/neoswitch:status [-v]` | Показать активную модель, статус входа Google и 5-часовые/недельные полосы квоты (`-v` добавляет все группы, кредиты, бэкенд и детали демона) |

|---|---|---|---|

| **Область действия** | **По одной сессии** (`/neoswitch:on`, `/neoswitch:off`); остальные окна работают с Claude | Глобальное переключение провайдера или общий локальный роутер | Глобальный `~/.claude/settings.json` или переменные окружения |
| **Функции Claude Code** | **Сохраняются** — без `ANTHROPIC_AUTH_TOKEN`, поэтому коннекторы `claude.ai`, `WebSearch`, режим Auto, живая квота и нативные команды работают как обычно | Управляются через внешний конфиг или роутер | Задаёт `ANTHROPIC_AUTH_TOKEN`, что отключает коннекторы `claude.ai` |
| **Вход через Google** | Использует аккаунт Google через официальный `agy` — **не читает, не хранит и не переиспользует OAuth-токены**; встроенные инструменты `agy` заблокированы | В основном API-ключи и сторонние релеи (без интеграции с `agy`) | Хранит или читает локальные OAuth-токены и напрямую вызывает приватные эндпоинты |
| **Лучше всего подходит для** | Обычной работы в Claude Code с точечным переключением отдельных сессий на Gemini 4 Neon | Управления множеством CLI, API-ключей, релеев и MCP в одном месте | Ротации нескольких аккаунтов, Windows или запуска моделей Claude через Antigravity |

## Полезно знать

- **Подпись модели:** Верхний заголовок Claude Code продолжает показывать имя модели Claude (например `claude-opus-5-5`), а `/model` не меняет модель бэкенда. В Claude Code 2.1.326 и новее строка состояния под приглашением показывает `Gemini 4 Neon answers this session`, пока NeoSwitch активен.
- **Задержка, `/effort` и размышления:** До первых слов ответа может пройти 5–40 секунд. `/effort low` ускоряет начало ответа (и в Antigravity, и в Gemini API / Vertex AI), а `NEOSWITCH_SHOW_THINKING=on` выводит рассуждения модели как блоки thinking в Claude Code.
- **Первый запуск после установки или обновления:** Первая команда NeoSwitch после установки или обновления может занять до минуты, пока собирается или загружается проверенный релизный бинарник.
- **Режим Auto:** Работает из коробки с встроенным fail-closed классификатором безопасности NeoSwitch (`gemini-3.8-flash` в Antigravity, нулевой расход Claude, без перезапуска). Задайте `NEOSWITCH_SAFEGUARD=off`, чтобы отключить его, или запустите Claude Code с `CLAUDE_CODE_AUTO_MODE_SERVER=0 claude`, чтобы действия проверял Claude через ваш аккаунт (расходует немного лимита Claude, с откатом на Gemini при отсутствии ответа).
- **Ежедневная подсказка:** После настройки NeoSwitch новая сессия без него не чаще раза в день на проект показывает однострочную подсказку `/neoswitch:on` (пропускается в проектах, где выполнялся `/neoswitch:off`; `NEOSWITCH_NO_HINT=1` отключает её).
- **Автоматические обновления:** О выходе новой версии сообщают заметка сессии и `/neoswitch:status`. При включённом auto-update открытые окна Claude Code автоматически переходят на обновлённый демон, как только запускается новая сессия.

## Выключить, обновить или удалить

- `/neoswitch:off` возвращает эту сессию к Claude со следующего сообщения, с вашим собственным входом в Claude. `/neoswitch:on` снова переключает её на Gemini 4 Neon без повторной настройки. Закрытие сессии завершает её переключение: каждая новая сессия начинается с Claude.

Чтобы обновить вручную, выполните в терминале следующее, затем откройте новую сессию Claude Code (уже открытые окна перейдут на новую версию автоматически):

```bash
claude plugin marketplace update neoswitch
claude plugin update neoswitch@neoswitch
```

Если вы добавляли маркетплейс под старым именем `yldm-ai/NeoSwitch` / `yldm-ai/neon-switch`, сначала добавьте его заново командой `claude plugin marketplace add yldm-ai/neo-switch`.

Чтобы удалить NeoSwitch:

1. Сначала выполните `/neoswitch:off` в каждом проекте, который вы переключили. Проект, оставленный включённым, продолжит указывать на NeoSwitch и перестанет отвечать, когда NeoSwitch не станет. Если плагин уже удалён, откройте `.claude/settings.local.json` в каждом таком проекте и измените объект `env`: удалите `ANTHROPIC_BASE_URL`, если он начинается с `https://127.0.0.1:` (в прежних версиях `http://127.0.0.1:`, вместе с соседним `ANTHROPIC_AUTH_TOKEN`); удалите строку `X-NeoSwitch-Token` из `ANTHROPIC_CUSTOM_HEADERS`, а если больше ничего не осталось — всю запись; удалите `NODE_EXTRA_CA_CERTS`, если он указывает на `tls/bundle.pem` в папке NeoSwitch, или верните свой файл CA, если он там был; и удалите `CLAUDE_CODE_GATEWAY_HINT_HEADERS` со значением `1` и `CLAUDE_CODE_USE_GATEWAY` со значением `0`, если вы не задавали их сами.
2. Закройте окна Claude Code, использующие NeoSwitch, и выполните в терминале:

```bash
claude plugin uninstall neoswitch@neoswitch
claude plugin marketplace remove neoswitch
```

3. Удалите файлы, которые NeoSwitch хранит вне ваших проектов:

| Что | Где |
|---|---|
| Программа NeoSwitch, которую плагин скачивает или собирает | `$XDG_CACHE_HOME/neoswitch/` или `~/.cache/neoswitch/`, если `XDG_CACHE_HOME` не задан |
| Состояние, TLS-пакет, изолированная папка `agy` и `daemon.log` | `NEOSWITCH_STATE_DIR`, если задан; иначе `~/Library/Application Support/neoswitch/` в macOS и `$XDG_CONFIG_HOME/neoswitch/` или `~/.config/neoswitch/` в Linux |

Вход в Google хранит `agy`, а не NeoSwitch, и он остаётся на месте; сам `agy` тоже остаётся, даже если его установил `/neoswitch:login`.

## Что меняет NeoSwitch

Пока сессия в проекте использует Gemini 4 Neon, NeoSwitch добавляет четыре записи в объект `env` файла `.claude/settings.local.json` этого проекта и удаляет их, когда ни одна сессия там его больше не использует:

- `ANTHROPIC_BASE_URL`, `ANTHROPIC_CUSTOM_HEADERS` и `NODE_EXTRA_CA_CERTS` направляют запросы Claude Code этого проекта в NeoSwitch на этом компьютере по зашифрованному соединению, на которое может ответить только NeoSwitch. Переключённым сессиям NeoSwitch отвечает с помощью Gemini 4 Neon, а все остальные запросы передаёт в Claude без изменений, с вашим собственным входом в Claude, который он не хранит и не записывает. Заголовок содержит ключ, открывающий только NeoSwitch на этом компьютере. Если в файле были ваши собственные `NODE_EXTRA_CA_CERTS` или `ANTHROPIC_CUSTOM_HEADERS`, NeoSwitch сохраняет их копию и возвращает ваше значение, когда удаляет свои записи.
- `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` заставляет Claude Code указывать в заголовке, пришёл ли запрос из основного диалога, субагента, сжатия контекста или фоновой задачи вроде подсказки промпта. NeoSwitch использует это, чтобы сохранять сессию Gemini за вашим основным диалогом. Если вы задали эту запись сами, NeoSwitch оставит ваше значение без изменений.

В Git-проекте NeoSwitch также добавляет `.claude/settings.local.json` в собственный список исключений клона (`.git/info/exclude`), чтобы токен не попал в коммиты; ваш `.gitignore` не меняется.

NeoSwitch работает только на этом компьютере и принимает подключения только с него. Он не записывает промпты, ответы, ключи и данные входа, и никакой наш сервер не участвует. Вход в Google остаётся внутри `agy`; NeoSwitch никогда его не читает.
